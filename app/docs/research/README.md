# Research

Point-in-time notes on things outside the codebase — the market, competitors,
funding, regulation. Separate from `docs/decisions/` because these are _inputs_ to
decisions, not the decisions themselves, and separate from `docs/todos/` because
nobody has to act on them.

**These go stale.** Every entry is dated in its filename and states when it was
written. Re-verify before leaning on a number.

- One file per topic: `YYYY-MM-topic-slug.md`.
- Link the entry from whatever decision it fed, and link back.
