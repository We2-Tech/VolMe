# Todos

Work that was intentionally deferred, recorded with enough context that whoever — human or agent — picks it up later doesn't have to reconstruct "why is this here" from scratch. This isn't a replacement for `// TODO:` code comments — when a deferral has one obvious anchor line, just write the comment. This folder is for what a one-line comment can't hold: cross-cutting cleanup, "we should eventually migrate to X", things noticed in passing but out of scope for the session that found them.

**Skim the index below before starting non-trivial work in an area. When a todo is resolved, delete its file and its index row in the same change — a todo left to rot here is worse than no todo at all.**

- One file per todo: `NNNN-short-slug.md`.
- Copy [`_template.md`](_template.md) to start a new entry.
